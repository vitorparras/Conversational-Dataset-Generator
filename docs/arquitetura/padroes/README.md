# Padrões de peça

> Descrição. O que entra nesta pasta.

Como cada tipo de peça se escreve neste projeto, a partir de um exemplar real do código. Os
limites (tamanho, parâmetros, composição, erros) estão em
[regras de código](../../regras-de-codigo.md) e não se repetem aqui; este guia diz **qual arquivo
copiar** e **o que não copiar**.

Diferente do resto de `docs/arquitetura/`, cada documento daqui é norma: o plano de uma fatia cita
o padrão de cada peça que toca, e quem revisa reprova o desvio. Se o exemplar mudar e deixar de
seguir o padrão, o documento é que se corrige, na mesma mudança.

Cada documento tem três partes: o exemplar (arquivo e linhas), o princípio que ele aplica e o que é
proibido, com um caso do código atual que ainda não segue o padrão, para que ninguém o tome por
modelo.
