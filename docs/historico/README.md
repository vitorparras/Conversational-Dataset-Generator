# Histórico

> Histórico. Autoridade zero.

Registro do que já aconteceu: análises, auditorias, decisões substituídas, medições feitas em
determinado momento.

**Nada aqui é regra, em nenhuma circunstância**, mesmo quando o texto parecer normativo. Um
documento histórico descreve o que era verdade quando foi escrito — não o que vale agora.

Documento histórico **não se divide nem se resume** para caber em limite de tamanho: dividir
falsificaria o registro.
