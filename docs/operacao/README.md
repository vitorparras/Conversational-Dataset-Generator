# Operação

> Descrição. O que entra nesta pasta.

Como rodar, implantar, salvar em backup, restaurar e verificar o sistema em funcionamento.

Inclui o que precisa ser executado periodicamente — verificação de integridade da custódia, por
exemplo. **Verificação que existe mas nunca roda não é garantia**, e é aqui que se registra quando
e por quem ela roda.

Ver [regras de escrita](../regras-de-escrita.md).
