# Privacidade

> Descrição. O que entra nesta pasta.

As políticas que governam o tratamento de dado pessoal: o que é pseudonimizado, o que é removido, o
que é **deliberadamente preservado** como contexto necessário, quem acessa o quê, o que fica
registrado e o que exige autorização.

Também a custódia: o que é imutável, como a integridade é verificada, e o que se faz quando ela
falha.

**Documentos aqui vinculam** (`Norma vigente`). Este projeto processa dados que podem envolver
investigação criminal; a política não é sugestão, é regra.

Cada política diz **qual camada impõe** o que ela promete — banco, aplicação, configuração de
ambiente ou processo humano — e o que acontece quando essa camada falha. Promessa sem mecanismo
nomeado é intenção, não garantia.

Aqui ficam a regra e a razão dela, inclusive o que vale para pessoas e processos. A garantia
observável que corresponde a cada regra, com critérios de aceitação, vive na pasta de requisitos e
cita a política de origem sem repetir a justificativa.
